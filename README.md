# Universal RAG

## Requirements

- Python 3.11+
- CUDA-capable GPU recommended
- Qdrant
- Node.js/npm for MCP Inspector

## Development

### Start the API

```powershell
.\.venv\Scripts\python.exe .\server\launcher.py
```




The API runs at:

http://127.0.0.1:8000

## Tests

Run the automated test suite:

```powershell
.\.venv\Scripts\python.exe -m pytest -v
```
